# Row-Level Security (RLS) Practice Project

## Project Overview

This project uses a sales dataset from a technology company selling products such as laptops, phones, routers, monitors, and keyboards across selected Nigerian states.

The main objective was to understand how Power BI can restrict data access so that different users only see the information they are authorized to view.

The project progressed from basic sales analysis to a static RLS, dynamic RLS, user testing, and a more advanced scenario where one manager can have access to multiple states.
